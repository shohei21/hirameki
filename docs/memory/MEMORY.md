ジャンルは「AI美女垢 × note販売」だが、骨格はどの発信ビジネスにも当てはまる。

| 項目 | 内容 |

## 2. 全体フレーム: 収益化までの4工程

```
①アカウント設計 → ②集客 → ③ファン化・教育 → ④商品販売
```

- マネタイズの本質はこの4つにまとまる
- **どれか1つだけ上手くてもダメ**。4つすべてを一定水準まで上げる
  - 設計が良くても集客できなければ見てもらえない
  - 集客できてもファン化できなければ「可愛い子がいる」で終わる
- 省エネ化できた一番の理由は、**この4つをテンプレ化して何度も回したこと**

### 料理のたとえ(反復で速くなる)
初めて作るハンバーグはレシピを見ながら120分かかる。10回作れば手順も分量も体が覚え、10分で作れる。
→ 1垢目が一番大変で、2垢目・3垢目と迷いが減っていく。
**最初から天才的な運用を目指さない。まず1回やり、もう1回やり、その中で無駄を削る。**

## 3. STEP1｜アカウント設計

### 1-1. 入口は多くの人に受ける見た目にする
- 一部の層に深く刺さる見た目(ギャル系・女王様系など)より、**多くの人が「普通に可愛い」と感じる見た目**のほうが母数を取りやすい
  - イメージ: 万人受けなら100人中80人が気になる。尖った見た目だと20〜30人に強く刺さる
- 初期はまず知ってもらうことが最優先。母数が大きいほど、その後ファン化できる人数も増える
- 補足: 慣れればポストで世界観を作って売れる(画像が少なくても月100万の例は多い)。初心者は見た目で目を止めるのが無難

### 1-2. 画像ではなく「人」を作る(最重要)
- 特徴・性格・普段の生活・家庭環境・恋愛遍歴・好き嫌い・コンプレックス・将来像まで決める
- 例: 「普段は明るいけど実は寂しがり」「仕事はしっかり、家では甘えたい」「昔の恋愛で傷ついた」
- **背景があると文脈が生まれ、読者の中で「AI画像」が「あの子」に変わる** → ファン化の土台になる
- 設定はすべて表に出さない。裏に細かく持っておき、日常ポストやストーリーで少しずつ見せる

### 1-3. ターゲットの根源的な欲求から逆算する
- 欲求の例: 見たい、癒されたい、認められたい、話を聞いてほしい、特別扱いされたい、日常にない刺激が欲しい
- **自分が発信したいことではなく、相手が何を感じたら反応するかから考える**
- 例: 承認されたい人には「今日も頑張ったね」より「◯◯さんに特別だよ」のほうが刺さることがある(「自分だけ」「特別」という感情を作れる)

### 1-4. 一貫性(世界観の統一)
- アイコン・名前・プロフィール・固定ポスト・文章・画像の雰囲気まで、**同じ1人のキャラとしてつなげる**
- バラバラだと、見る側が無意識に違和感を持つ(意図的なギャップはOK)
- ゴールは設定資料を作ることではなく、**読者が「この子ってこういう子だよね」と同じ印象を持てること**
- 最初に軸を固めるほど後が楽になる。ブレると後で全部直すことになる → **最初に時間をかけるほうが結局は省エネ**

## 4. STEP2｜集客

### 2-1. まず知ってもらう
- 見てくれる人が0人なら何も始まらない → とにかく入口を増やす
- **初めて見た人が1〜2秒で目を止められる投稿**にする
  - NG: 内輪ネタ、前後を読まないと分からない投稿、設定を知っている前提の文章
- 「可愛い」「何してるんだろう」「ちょっと見たい」くらいの感情が動けば十分

### 2-2. 見込み客へ自分から近づく
- 待っているだけでは時間がかかる → **見込み客がいる場所へ自分から行く**(同じジャンルの垢と交流する)
- 目的は売り込みではなく、存在を知ってもらうこと
- 導線: プロフィールを見る → 固定ポストを見る → 何件か読む → 「ちょっといいかも」
- **フォロワー数より、見込み客との接点の数を追う**

## 5. STEP3｜ファン化・教育(売上の核)

> 今日初めて見た相手に「note出しました、買ってね」と言われても買わない。まだ興味が弱いから。

### 3-1. ファン化ゲージ(0→100)

| ゲージ | 状態 | 打ち手 |
|---|---|---|
| 0 | まだ知らない | (集客) |
| 20 | 少し気になる | 日常やキャラを見せる |
| 40 | もっと見たい | ストーリーを見せる |
| 50 | 何してるんだろう | |
| 60 | もっと知りたい・頭から離れない | 価値観や秘密っぽい話を入れる |
| 80 | この子じゃなきゃダメ | 「この子の商品なら見たい」に近い状態 |
| 100 | 早く商品を!! | 販売 |

- 運用側が「この人は今どのくらいの温度か」を意識するだけで発信が変わる
- **一気に100を狙わず、少しずつ上げる**
- **ゲージを数値化すれば自動化にも使える**(← 自分の型づくりで特に使えそうな考え方)

### 3-2. ストーリーで「ただの画像」を「この子じゃなきゃダメ」に変える
- 今日あったこと、仕事、過去の経験、悩み、コンプレックス、これからしたいこと
- 積み重なると人物像ができ、「前に言ってた話どうなった?」とアカウントの外に物語が生まれる
- フォロワーが**ポスト単体ではなくアカウント全体を追い始める**
- 商品も「あの子が出したものだから気になる」と見てもらえる

### 3-3. 教育 = 「商品を知らない」を「欲しい!」に変えること
いろいろな角度から伝える:
- この商品で何が得られるか
- どんな欲求が満たされるか
- 買った後にどんな楽しい未来があるか
- なぜ今なのか
- なぜ他ではなくこれなのか

**核心: 商品そのものではなく、手にした後の感情や体験をイメージさせる。**
教育は販売直前だけでなく、普段のポストや無料noteで積み上げる。
「興味を持たせる → 価値を伝える → 欲求を膨らませる → 今見る理由を作る」

### 3-4. 「欲しい」を作ってから商品を出す
- 一番しんどいのは、出してから必死に売ること
- 販売前から伏線を張る:「実は最近ちょっと色々あって」「これ誰にも言うつもりなかったんだけど」
- 商品が新しい話ではなく、**ずっと気になっていた話の続き**になる
- 販売を当日だけのイベントにしない → ローンチ期間に作業量が急増するのを防げる

## 6. STEP4｜商品

### 4-1. 毎回ゼロから作らず型を作る
- 商品ジャンルの例: 自己開示系 / 会うノウハウ系 / セクテク系 / 体験記系
- **月200万のときは「自己紹介系」に固定した**
- 型として決めること: 導入 → 入れるストーリー → 中身を見せる順番 → 販売へのつなぎ方
- 2回目以降は、キャラ・エピソード・言い回しなど**必要な部分だけ差し替える**
- 型の再利用は手抜きではない。同じ型を使って反応を見て改善するので、回数を重ねるほど精度が上がる

### 4-2. note作成を時短する
- 何本か書くと判断基準が身につく: どんな冒頭なら読まれるか、実績・共感・具体例をどこに置くか、どこで欲求を上げるか
- その判断基準をマニュアル化して**AIや外注に渡す**
  - 渡すもの: 過去の記事 / 自分の口調 / 構成 / 今回伝えたい内容 / ストーリー / NG表現
- 「いい記事書いて」と丸投げしても狙った文章にはならない → **正解例を言葉にして渡す**
- 実例: 自己紹介系noteの型を作り、AIで執筆し、チェックも含めて外注に任せた
- **自分がやるべきこと以外は任せる**

## 7. STEP5｜複数垢を時短で回すコツ

### 原則: 1回やったことを資産にする
- 商品ジャンルを固定してテンプレ化する(ノウハウ系と自己紹介系では訴え方が変わるため)
- 興味づけ → 匂わせのタイミング → 中身 → 販売導線、の流れを使い回す →「はいはい、この流れね」の状態になる

### アカウントごとに変えるもの / 変えないもの

| 変える(見た目) | 変えない(本質) |
|---|---|
| キャラクター | 集客: 見込み客を集める |
| 世界観 | ファン化: 「この子じゃなきゃダメ」まで熱量を上げる |
| ストーリー | 教育: 「知らない」から「欲しい」へ |
| 言葉遣い | 販売: 最後に商品を届ける |
| 刺したい欲求 | |

### 無駄を削る
- 「時間がかかる割に売上が変わらない作業」は削る
- **削る基準は、時間がかかるかどうかではなく、売上への影響が小さいかどうか**
- 設計・集客・興味づけ・ファン化・教育・販売導線のように、売上に直結する部分は残す

### 外注・AIに渡す
- 再現性が高い = 外注やAIでもできる
- 判断基準を言葉にする:「この場合はこうする」「この数字なら次はこれ」「このキャラならこの方向」「このタイミングで教育を入れる」
- 対象: 画像生成、ポスト作成、商品作成、分析、改善

```
自分で実践 → 型を作る → 無駄を削る → 外注へ渡す → AIへ渡す
```

## 10. 自分の型を作るときのメモ

### そのまま取り入れたい骨格(ジャンルを問わない部分)
1. **4工程の分解**: 設計 → 集客 → ファン化・教育 → 販売。どれか1つに偏らず、全工程を一定水準にそろえる
2. **型化の順番**: 自分で実践 → 型にする → 無駄を削る → 外注 → AI。いきなりAIに渡さない
3. **判断基準を言葉にする**: 「この状態ならこうする」をルールにできた部分から自動化できる
4. **ゲージで考える**: 相手の温度を数値で表し、段階ごとに打ち手を決める(状態遷移として設計できる)
5. **変える部分と変えない部分を分ける**: 表面(キャラ・言い回し)は入れ替え、本質(流れ)は固定する
6. **商品を固定する**: 売り物を1つに絞ると、教育や導線のテンプレがそのまま使い回せる
7. **販売は伏線の回収**: 普段から「何があったの?」を作り、商品をその続きとして出す
8. **削る基準は成果への影響**: 所要時間ではなく、成果への寄与で残すかどうかを決める

### 自分向けに考え直すポイント(問い)
- 自分の題材で「人を作る」(1-2)にあたるものは何か? 読者の中で「情報」が「あの人/あのもの」に変わるきっかけは?
- 自分の読者の根源的な欲求は何か? 自分が言いたいことではなく、相手が反応することから逆算できているか?
- 自分版のゲージ(0→100)は何段階で、各段階の打ち手は何か?
- 固定する商品(型)は何か? 2本目以降で差し替えるのはどこか?
- 判断基準のうち、すでに言葉にできているもの・まだできていないものは?
- 今の作業のうち、成果への影響が小さいものはどれか?

### 注意点(取り入れるときに切り分けること)
- 元の事例は、**AIで作った架空の女性を実在の人物のように見せ、恋愛的・性的な欲求に訴えて有料noteを売る**モデル。骨格(型化・反復・自動化・段階的な関係づくり)は汎用的だが、「架空の人物を実在に見せる」「自己開示や体験談を作り話で書く」「会うノウハウを売る」といった部分は、読者をだますことになりかねない
- X やnote のAI生成コンテンツ・成人向けコンテンツに関する規約、特定商取引法などの表示義務も、取り入れる前に確認する
- 自分の型では、**骨格だけを借りて、中身は誠実に出せる題材で組み立てる**ことを前提にする
