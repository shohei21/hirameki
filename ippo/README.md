# Ippo — 今日の一動作

「やった方がいいのは分かっている」のに動けないとき、意志の強さではなく
**始めようとしていることの大きさ**を見直すためのブラウザアプリ(PC・スマホ対応、ホーム画面に追加可)。

## 考え方

- 大きな目標(やりたいこと)はそのままでいい。小さくするのは**最初の一歩**だけ。
- 「これを2分だけ進めるなら、何に手をつける？」に、**手の動きが分かるくらい具体的に**答える。
- やってみる。続けられそうなら続ける。止めるなら**次にやる一動作**をメモしておく(再開時に迷わない)。
- 最初の一歩の役割は達成ではなく、次に何が必要かを見えるようにすること。

## 画面

| タブ | できること |
|---|---|
| 一歩 | 目標ごとの「次の一動作」が並ぶ。タップ → 一動作を決める → タイマー → 振り返り(見えたこと・次の一動作) |
| 記録 | 今日/連続日数/合計の一歩・分、直近28日のマス目、日別ログ、共有用の要約コピー、バックアップ |
| 目標 | 目標の追加・編集・並べ替え・しまう/削除、タイマー目安(2/5/10/15分)の初期値 |

一動作を入力すると、「頑張る」「進める」「いい感じに」のような曖昧な言葉や、完成度を求める言葉、
手の動きが見えない文に気づかせるヒントが出ます(ヒントだけで、開始はブロックしません)。
「重い？もっと小さくする」で、目標ごとの例と「開くだけ」などの小さくするはしごを選べます。

## データ

- サーバー・APIキーなし。すべてこの端末の `localStorage`(`ippo:v1:data`)に保存。
- 実行中のタイマーは開始時刻ごと保存するので、スマホで画面を閉じたりリロードしても続きから戻れます。
- 端末を移るときは「記録 → バックアップ」でJSONを書き出し/読み込み。

## 開発

```bash
npm install            # リポジトリ直下で
npm run dev:ippo       # http://localhost:5174
npm run test -w ippo
npm run typecheck -w ippo
```

GitHub Pages では Hirameki と同じサイトの `/hirameki/ippo/` に配信されます(`.github/workflows/deploy.yml`)。
